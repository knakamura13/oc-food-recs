# Near me implementation plan

**Goal:** Complete #158: retain user coordinates, rank by straight-line distance, narrow by radius, and expose the latest mention date.

**Architecture:** Session-only browser state supplies a shared location request and a pure haversine helper. Radius joins the existing shared filter pipeline so list, map, histogram and facet counts agree. Shared URLs omit local location-dependent state. No database or analytics changes.

**Tech stack:** Svelte 5, TypeScript, Leaflet, Vitest and Playwright.

1. Add failing tests for distance, missing coordinates, radius across filters/facets, permission failures and cancellation, shared-link privacy, and rendered controls/rows.
2. Implement `distance.ts`, `location.ts`, and store state/reset; extend sort keys, labels and URL handling.
3. Apply radius in `filter-page-restaurants.ts`; forward state from `ExplorerApp.svelte` and fit map after radius changes.
4. Add Near me, radius (all distances, 1/2/5/10/25 miles), disclosure and forget-location actions to `FilterBar.svelte`. Keep controls outside the overflow rail and at least 44px high on phones.
5. Add distance sort and row distance/date tags to `RestaurantList.svelte`; update Leaflet's existing location button and blue dot to consume the same location state.
6. Explain browser-only location handling, straight-line miles, location-centered third-party map tiles, and comment-date limitations on `/about`.
7. Run focused tests, full unit suite, type checks, build and phone/desktop browser checks. Inspect final diff, commit, push, open PR, verify CI and update the issue. Merge remains a separate authorization boundary.

Design follows the existing issue specification. Permission is requested only on a button click; failure leaves results unchanged. Unmapped rows sort last in both directions and are excluded by an active radius. Age is disclosed without automatically excluding old recommendations. Reload drops location and radius; sharing keeps portable filters and uses the default sort instead of distance.
